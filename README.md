# Retail Sales Forecasting using Machine Learning

## Project Overview
This project analyzes historical retail sales data and uses Machine Learning to forecast future sales. Python is used for data preprocessing, exploratory analysis, visualization, model development, and evaluation.

The project applies Linear Regression to historical monthly sales data to predict future sales trends.

## Objectives
- Analyze historical retail sales patterns.
- Explore monthly sales trends and growth.
- Visualize sales performance.
- Build a Machine Learning model for sales prediction.
- Forecast future monthly sales.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Model
**Algorithm:** Linear Regression

The model uses time-related features to learn historical sales patterns and predict future sales.

## Model Evaluation
The model was evaluated using the following metrics:

| Metric | Value |
|---|---:|
| MAE | 4362.55 |
| RMSE | 5281.22 |
| MAPE | 22.99% |

## Visualizations
- Average Sales by Month
- Monthly Total Sales Trend
- Actual vs Predicted Monthly Sales
- Historical Sales vs Future Sales Forecast

## Future Forecast
The model generates a 12-month sales forecast for 2018 based on historical sales patterns.

## Project Files
- `Sales_Forecasting.ipynb` – Complete analysis and Machine Learning implementation.
- `stores_sales_forecasting.csv` – Dataset used for analysis and forecasting.

## Conclusion
This project demonstrates the use of Python and Machine Learning techniques to analyze historical retail sales and generate future sales forecasts. It provides practical experience in data analysis, visualization, model development, and evaluation.
